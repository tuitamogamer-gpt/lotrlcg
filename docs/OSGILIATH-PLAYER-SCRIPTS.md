# Assault on Osgiliath player scripts

The ten player designs from **Assault on Osgiliath** (`06081`–`06090`) have explicit automated rules. Sword of Morthond reuses its existing passive trait rule. This document covers the player cards; it does not claim automated support for the Osgiliath scenario or its Nightmare version.

## Sources and rules decisions

- Imported card text and printing metadata: the retained RingsDB official catalog records in `src/data/osgiliath-player-cards.json`.
- [Fantasy Flight Games product page](https://www.fantasyflightgames.com/en/products/the-lord-of-the-rings-the-card-game/products/assault-on-osgiliath/): pack identity and cycle.
- [FFG FAQ 1.9](https://cdn.svc.asmodee.net/production-fantasyflightgames/uploads/2026/09/lotr_faq_19_printer_friendly.pdf), section **1.55 Lasting Effects**: Gondorian Fire calculates its attack bonus after spending the required resource. The resulting bonus remains fixed until phase end even if the resource pool changes or the attachment leaves play. The printed original [FAQ PDF](https://images-cdn.fantasyflightgames.com/filer_public/2e/31/2e3129b3-dc51-4c27-81ed-6a72f13e82f3/lotr_faq_19.pdf) contains the same section.
- [FFG Rules Reference](https://images-cdn.fantasyflightgames.com/filer_public/90/19/90191e4e-a341-4379-b398-5963b7a87ebf/mec01_online_only_rules_reference_for_website.pdf): **Costs**, **Event Cards**, **Ownership and Control**, **Printed**, **Restricted**, **Response**, **The word Choose**, and **Timing of Ability Resolution** supply the common rules. Knight's response is granted by printed Tactics icons, triggers on entry by either play or a put-into-play effect, and requires actual exhaustion even when Path of Need removes ordinary attack exhaustion. These are applications of the printed card and common rules rather than a card-specific FAQ ruling.

## Implemented clauses

| Code  | Design                 | Automated behavior                                                                                                                                                                                                                                                                                                              |
| ----- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 06081 | Faramir                | Ranged; continuous +1 attack per enemy currently in the shared staging area.                                                                                                                                                                                                                                                    |
| 06082 | Sword of Morthond      | Gondor ally attachment restriction; Outlands trait from the existing passive handler, including interaction with Outlands bonuses.                                                                                                                                                                                              |
| 06083 | Men of the West        | Explicit positive X, normal matching resource payment, exactly X selections of printed Outlands allies from the controller's discard pile. Duplicate designs are selected by actual current discard index. Resource surcharges affect payment without changing X.                                                               |
| 06084 | Knight of Minas Tirith | Optional entry response only for an owner with exclusively printed Tactics heroes; legal staging enemy engagement, engagement consequences, then immediate single-Knight attack with actual exhaustion. Ordinary attack rights remain available afterward.                                                                      |
| 06085 | Gondorian Fire         | Gondor or Dúnedain hero host; spend one resource from that hero's own pool, apply a fixed bonus equal to the post-cost pool, once per physical attachment per phase.                                                                                                                                                            |
| 06086 | Pelargir Shipwright    | Continuous willpower equal to its controller's current printed Spirit heroes. Gained resource icons and other players' heroes do not count.                                                                                                                                                                                     |
| 06087 | Map of Earnil          | Spirit hero host, including gained icons; printed Spirit hero discount; explicit legal event, target and complete payment choices before discarding the Map. The selected physical event stays outside discard while resolving and finishes on the bottom of the controller's deck unless its own text changes its destination. |
| 06088 | Ranger Bow             | Ranger character restriction and Restricted slot; chosen staging enemy; attachment and host must both actually exhaust before dealing one damage.                                                                                                                                                                               |
| 06089 | Forest Patrol          | Requires a Ranger controlled by the player; three damage to an eligible enemy with a faceup, unblanked Trap attachment in staging or engagement.                                                                                                                                                                                |
| 06090 | Palantir               | Noble hero restriction and Planning Action timing; name a card type before inspection, exhaust attachment and hero, inspect up to three existing encounter cards without changing order, draw once for each matching card and raise threat by two for each mismatch.                                                            |

The implementation preserves attachment controller versus physical owner, immunity and movement restrictions, event cancellation after costs, common damage and exhaustion consequences, phase expiration, and serialized effect choices. Map excludes its own resolving event as a discard target: Dwarven Tomb cannot retrieve itself or accidentally retrieve the card that shifts into its old discard position.

## Validation

`node --import tsx --test tests/osgiliath-player-cards.test.ts` passes **28/28** semantic tests through the public engine. Tests cover each design, printed versus gained resource icons, duplicate discard choices, X versus surcharge, optional entry, put-into-play entry, Path of Need, lasting bonuses, paid replay and physical event identity through saved nested choices, cancellation, Restricted slots, ownership, Trap eligibility, encounter order, short decks, blocked draw, and Iron Shackles consuming only the first per-card draw instruction.

`GAME_URL=http://127.0.0.1:5203 node --import tsx scripts/browser-osgiliath.mjs` passes actual UI journeys at **1280×900, 390×844, and 320×750**, using reduced motion. Men of the West's X input and payment, Palantir naming and inspection, Map's paid replay, and Knight's optional response and required exhaustion are exercised through visible controls and reloads. The run confirms no horizontal overflow, bounded dialogs, and no page or console errors. Screenshots are in `output/osgiliath/`.

No commit, push, or deployment is part of this pack's scripting verification.
