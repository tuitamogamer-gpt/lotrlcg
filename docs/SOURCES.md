# Data and asset provenance

Published-content snapshot verified on 2026-09-30. No credentials are needed for the implemented public APIs. The complete reference import, source hashes, reconciliation rules and automation boundary are documented in [CONTENT-IMPORT.md](CONTENT-IMPORT.md); retail products and preconstructed deck recipes are documented in [PRODUCT-SOURCES.md](PRODUCT-SOURCES.md). Earlier Core Set sourcing below was verified on 2026-09-23 unless another date is given.

- [RingsDB API documentation](https://ringsdb.com/api/doc): the initial 2026-09-23 `GET https://ringsdb.com/api/public/cards/` response returned 1,315 player-card definitions; `GET https://ringsdb.com/api/public/cards/core.json` returned 73. The public response includes `Access-Control-Allow-Origin: *`. The current `public/catalog.json` combines reconciled RingsDB player cards with the complete official DragnCards encounter, campaign and Nightmare library. `npm run sync:cards` refreshes the reference snapshot and validates its cross-references before replacement. `src/data/player-cards.json` supplies the curated engine definitions and original printing quantities and is preserved by this importer.
- [RingsDB API usage guidance](https://ringsdb.com/api/): public versus OAuth endpoints, CORS, cache guidance, and original text ownership. No OAuth is needed for card reads. No official Fantasy Flight card API was identified.
- [OCTGN Core Set](https://github.com/GeckoTH/Lord-of-the-Rings/blob/master/o8g/Sets/Core%20Set/set.xml): encounter stats, text, shadows, quantities, and alternate quest faces. Normalized into `src/data/encounter-cards.json`. Fixed the display spelling of Chieftain Ufthak while retaining the source image filename.
- [FFG encounter-set inventory](https://www.fantasyflightgames.com/ffg_content/lotr-lcg/support/lord-of-the-rings-core-set-encounter-list.pdf): validated the original 36-card Passage Through Mirkwood deck, including the two cards placed in staging at setup.
- [FFG Rules Reference](https://images-cdn.fantasyflightgames.com/filer_public/f2/87/f28704b2-5f25-4fd8-be7a-18d4a5d2c1c4/mec101_core_set_rules_reference_v10c-compressed.pdf): setup, phase order, payments, shadows, questing, damage, and victory. This implementation has explicit timing limitations listed in COVERAGE.md.
- [Hall of Beorn Core Set catalog](https://www.hallofbeorn.com/LotR/Products/Core-Set?View=Browse): cross-check of starter quantities and encounter scans. The four original learning decks each contain 29 sphere cards plus one Gandalf, with three separate heroes. These are the original introductory decks, not the later standalone faction starter products or tournament-size constructed decks.

- [FFG Revised Core Set campaign cards, hosted by Hall of Beorn](https://hallofbeorn-resources.s3.amazonaws.com/Images/LotR/Print-and-Play/core_set_campaign_cards.pdf): all three campaign setup/resolution cards and seven boon/burden definitions. Cross-checked against the [Revised Core Set catalog](https://www.hallofbeorn.com/LotR/Products/Revised-Core-Set?View=Browse) and the Rules Reference campaign section. Mirkwood Paths is one campaign connecting the Core Set’s three quests. The Dark of Mirkwood contains expansion quests and is not included.
- All three normal encounter decks use the OCTGN Core Set quantities and printed quest fronts/backs: Mirkwood 36, Anduin 47, Dol Guldur 41. Together the Core Set has 45 distinct non-quest encounter definitions and 84 physical encounter cards; the scenario decks reuse encounter sets. The source quest set is named “Journey Down the Anduin,” while the scenario is “Journey Along the Anduin.”

## Artwork

- `public/cards/01001.png`–`01073.png`: original card scans from RingsDB `/bundles/cards/`. Cached locally for stable play and preserved with original artists/ownership. Celebrían’s Stone required a cache-busted request; its returned image was normalized to PNG.
- The 45 Core Set `public/cards/*.jpg` encounter scans: Hall of Beorn `/Images/Cards/Core-Set/`, including `Dol-Guldur-Orcs-Enemy.jpg`, the source spelling `Chieftan-Ufthak.jpg`, and the unaccented `Nazgul-of-Dol-Guldur.jpg`.
- `public/cards/rc132.jpg`–`rc138.jpg`: campaign support scans from Hall of Beorn’s `/Images/Cards/Revised-Core-Set/`. The `rc` codes are application-local identifiers matching revised card numbers, not RingsDB API codes. `public/cards/orc-guard.svg` is an original geometric facedown card back for player-deck Orc Guards.
- Card artwork and rules text remain the property of Fantasy Flight Games and their respective owners. This project is an unofficial fan implementation, with attribution in the in-app guide. No rights transfer is implied by API availability.
- `public/art/mirkwood.jpg`: original background generated with the built-in image-generation tool, then optimized as JPEG for the application. The generated original was copied from the Codex output directory; the application uses only the workspace copy.
- `public/art/anduin.jpg` and `public/art/dol-guldur.jpg`: original river and fortress scenery generated with the built-in image-generation tool for the interface refresh, then optimized as JPEGs. Exact prompts are preserved in [UI-REFRESH.md](UI-REFRESH.md).

## The Hunt for Gollum

Card statistics and quantities come from the OCTGN set definition (`o8g/Sets/The Hunt for Gollum/set.xml`, GeckoTH mirror) and the Hall of Beorn scenario page, which also records the official easy-mode quantities used for every quest. Encounter scans `public/cards/02014.jpg` to `02024.jpg` and the quest faces in `public/cards/quests/the-hunt-begins-*.jpg`, `a-new-terror-abroad-*.jpg` and `on-the-trail-*.jpg` are cached from Hall of Beorn's image archive on 2026-09-29. The adventure reuses the original Anduin scenery and playmat.

The 2026-09-30 review checked successful-quest timing against [FFG FAQ section 1.24](https://images-cdn.fantasyflightgames.com/filer_public/1d/bb/1dbb319c-6b1e-466e-9177-75a5857b5cfa/lotr_faq_19_printer_friendly.pdf): Forced effects and optional responses precede progress placement. Guarded objective ordering follows the [FFG Rules Reference](https://images-cdn.fantasyflightgames.com/filer_public/90/19/90191e4e-a341-4379-b398-5963b7a87ebf/mec01_online_only_rules_reference_for_website.pdf). The [original Hunt rules insert](https://images-cdn.fantasyflightgames.com/filer_public/ed/4a/ed4a71bb-0ed3-43eb-b6af-1a1dd22a4d0d/rulesheet-thehuntforgollum.pdf) and cached printed scans support the Clue, first-player, location surcharge and cancellation fixes. Deckbuilding legality follows the linked Learn to Play: matching spheres are payment advice rather than a deck-construction restriction.
