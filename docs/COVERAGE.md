## Timing boundaries

This is a playable implementation, not a certified complete rules engine for the entire game.

- Resource collection and draw are automated, then each player has an explicit Resource action window before Planning. Standard refresh steps ready characters, raise threat, pass the first-player token and resolve regeneration before Refresh actions. The visible phases provide action windows, including a post-staging window before quest resolution. The engine does not expose every intermediate action window inside an attack or between individual framework steps. For example, Swift Strike, Hasty Stroke and Behind Strong Walls have prompts, but arbitrary events are not available at every internal attack step.
- Event reviews are presentation pauses, not additional legal card-action windows. Rules-required choices still follow their existing timing. Resource/draw and refresh changes can be summarized together, and one card effect can contain several explicitly listed changes; these are not claims of a separate confirmation for each individual rules instruction.
- Legolas/Blade of Gondolin progress responses resolve separately in the player's chosen order, and Beorn/Sneak Attack departures offer the first player a timing choice. Other optional responses can still use a fixed order (for example Théodred before Aragorn). Mendor's ready/draw and prisoner rescue remain automatic. There is no general response-order editor. Valor, targeted responses, and cancellation use explicit prompts.
- Ranged, Sentinel, and Wandering Took have cross-seat targets in hot-seat games. A classic solo game has no other player to target. The interface is local and every seat is controlled by the same user.
- Brok, Valiant Sacrifice, Strength of Will, Swift Strike, and cancellation effects are available through engine-triggered prompts, not unrestricted hand actions.
- X-cost cards and multi-pool payments require explicit payment selection. Imported saves preserve pending choices; undo intentionally reveals information in this local solo setting.
- Original introductory single-sphere decks are preserved even for the harder quests. These are 30-card learning decks, not optimized constructed decks; Dol Guldur is particularly difficult solo. New games use three heroes per player, so Dol Guldur leaves two heroes available in a solo game. Legacy saves retain their original hero count; a saved one-hero player still cannot pay A Thicket of Spears from three different hero resource pools.

## Validation

Focused engine tests cover the quest gates, encounter/shadow mechanics, objectives, campaign rewards, permanent effects, captive characters, hero changes, retries, saves, and victory. Deterministic complete-game simulations derive their adventure list from the runtime registry and use all four original Core starters. Normal games cover every registered adventure; campaign simulations cover the three supported Core chapters. Separate seeded hot-seat runs cover 1–4 seats across the Core quests in normal and campaign modes. The simple legal-action policy checks state integrity, serializability, and termination; these runs do not establish balance, strong strategy, or exhaustive rules compliance.

Player-control tests cover durable pauses, stale confirmation rejection, reveal-before-effect, shadow-before-modifier-before-damage, cancellation, individual engagements, quest/terminal gates, save validation, and hidden information. Paired complete games compare guided, hidden-information and decisions-only outcomes with unpaced rules outcomes across the registered adventures; presentation history is removed before comparison. Some seeded hot-seat runs also exercise guided progression. The dedicated browser pacing suite uses real manual confirmations; older rules-focused browser suites explicitly acknowledge reviews to reach their existing interactions.

Browser checks exercise actual controls for all four starters, each normal quest, and the three-chapter campaign. Controlled checkpoints are used for victory/reward and rescue cases; these are not claims of three naturally won games. Checks cover mode selection, independent saves/reload, hero replacement, chapter transitions, prisoner choice, objective claims, Mendor rescue, the final reward, card inspection, payments, and desktop layouts from 1280×720 to 2560×1440. New hot-seat checks cover setup counts, separate hands, round handoffs, first-player rotation, reload, Sentinel, Ranged, borrowed attachments, replacement seat continuity, and keyboard control. New published-content and expansion-rule journeys are also checked at320/390/1280px, including saved objective choices and mandatory quest selection. See `progress.md` for release evidence.
